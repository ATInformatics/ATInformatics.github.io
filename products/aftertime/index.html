Music production

You didn't start making music to rename 40 tracks.

AfterTime is a music-production calculator. “Make the vocal more forward without making it louder” is not a request for advice. It is a constrained problem with measurable operations, and that is how it is solved.

It reads the session honestly

Tracks, folders and routing, including telling a real sidechain feed apart from a duplicated signal. Also every plugin, with whether it is actually switched on.

It measures takes

Cents off the note. Milliseconds against the grid. Which takes are the same performance, and which one covers most of the song.

It plans the comp before it moves anything

A base take, a map of the holes, the fills. All shown to you first.

It finds what is burying the vocal

Renders the stems and compares them band by band, so a complaint becomes a frequency and a number.

It proposes, you decide

Nothing that changes how the record sounds happens because a number improved. Taste stays with the producer.
