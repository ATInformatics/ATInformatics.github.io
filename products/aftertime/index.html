You didn't start making music to rename 40 tracks.

AfterTime is a music-production calculator. “Make the vocal more forward without making it louder” is not a request for advice — it is a constrained problem with measurable operations, and that is how it is solved.

Detail

The mechanical half of finishing a song.

  • It reads the session honestlyTracks, folders and routing — including telling a real sidechain feed apart from a duplicated signal — and every plugin, with whether it is actually switched on.
  • It measures takesCents off the note. Milliseconds against the grid. Which takes are the same performance, and which one covers most of the song.
  • It plans the comp before it moves anythingA base take, a map of the holes, the fills — shown to you first.
  • It finds what is burying the vocalRenders the stems and compares them band by band, so a complaint becomes a frequency and a number.
  • It proposes, you decideNothing that changes how the record sounds happens because a number improved. Taste stays with the producer.

Install

One command.

Needs REAPER (started once) and Python 3.10 or newer. Everything lands inside your own user account — no Administrator, no root.

python3 aftertime_setup.py

It shows you the licence and asks you to accept before it writes anything, builds its own isolated runtime, installs the bridge into REAPER, then re-reads all of it back and reports what is actually there.

python3 aftertime_setup.py --verify
python3 aftertime_setup.py --uninstall

Straight about Windows. The installer handles Windows paths and copies the bridge rather than symlinking it, so it works without Administrator rights. Nobody has run it on Windows yet. Treat it as experimental and tell us what breaks.
