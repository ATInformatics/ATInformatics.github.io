04 / Method

Measured, not asserted.

Every product here reports what it checked. These are the rules it was built under.

A write is not believed until it is read back

Software can report success and still have left the wrong result. Every change is re-read from the thing it changed.

Measurements come from the output

Not from the setting. A fader that moved and a sound that changed are two different facts, and only one of them is evidence.

Refusing is a feature

Wrong project, stale state, a measurement that would be meaningless. Each one stops the work and says which. A tool that quietly does the wrong thing to your file is worse than one that does nothing.

It proposes, you decide

Nothing that matters happens because a number improved. The cost of every suggestion is stated next to it.

If it is not proved, it says so

Including on this website. Where something has not been verified, the page says that instead of rounding up.

Start a conversation.

A project, beta access, or a question about what any of it actually does. It reaches a person.
